# 输出说明

本项目在启动真实 H/Cu(111) 计算前，把研究问题、结构模型、参考态和判断标准写成一份可以据此安排作业的计算备忘录。

## 应先读什么、回答什么

先写自己的备忘录，再读 output/answer.md。完成后应能让另一位研究者仅凭你的文档就知道要算哪些结构、比较什么、什么结果会使原判断失效。

## 用于理解这些结果的背景

电子结构软件能够输出能量和力，但不会替研究者决定这些量应该回答什么问题。“研究 H/Cu 催化”过于宽泛；“在指定覆盖度和真空 PBE 模型下，H 相对半个 H₂ 的吸附电子能符号是否稳定”才对应明确的结构、参考与检验。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
