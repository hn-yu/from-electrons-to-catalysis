# 01 · 先写计算备忘录，再申请资源

本项目在启动真实 H/Cu(111) 计算前，把研究问题、结构模型、参考态和判断标准写成一份可以据此安排作业的计算备忘录。

## 背景：为什么需要这一步

电子结构软件能够输出能量和力，但不会替研究者决定这些量应该回答什么问题。“研究 H/Cu 催化”过于宽泛；“在指定覆盖度和真空 PBE 模型下，H 相对半个 H₂ 的吸附电子能符号是否稳定”才对应明确的结构、参考与检验。

备忘录把科学判断转成计算设计：先确定观测量，再确定组成它所需的独立能量；先声明能接受多大变化，再安排能否定当前假设的设置扫描。这样做的价值是让算力投入对应某个不确定性的减少。

给定模型只有中性真空表面，不包含溶剂、电极电位或有限温构型熵。说明这些条件是为了界定问题本身，避免把一个电子吸附能计算解释成尚未建模的实验催化活性。

## 开始前需要理解的概念

- **目标观测量**：最终用于判断假设的量，本例为同一参考下的吸附电子能。
- **模型范围**：材料、晶面、覆盖度、环境和电子结构近似的共同定义。
- **误差容限**：在结果出现前规定何种数值变化足以改变判断。
- **否定实验**：专门寻找当前假设可能失败的设置或物理条件。

## 本次任务：从什么得到什么

读取 clean.POSCAR、fcc.POSCAR 与 calculator.toml，核对原子数、层数、真空和固定原子。写出吸附反应、所需 H₂ 参考、0.05 eV 容限与优先收敛轴，并规划 Slurm 作业和日志归档。这里交付的是计算设计及理由。

## 先用一个小例子走通思路

1×1 Cu(111) 表面胞每层有一个表面位点，放一个 H 对应 1 ML。若原计划讨论低覆盖度孤立吸附，这套输入已经改变了所问问题，不能等结果出来再补一句“使用小胞”。

吸附能需要含 H 表面、清洁表面、H₂ 三个参考。只完成含 H 表面的一个总能，即使它已电子收敛，也还没有得到吸附反应的能量。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

- [calculator.toml](input/calculator.toml)
- [clean.POSCAR](input/clean.POSCAR)
- [fcc.POSCAR](input/fcc.POSCAR)

```math
E_{ads}=E_{slab+H}-E_{slab}-\frac12E_{H_2},\qquad\theta_H=N_H/N_{surface\ sites}.
```

输入给出基准 clean/fcc POSCAR 与 calculator.toml。基准为 1×1×3，一个 H 即 1 ML。电子结构模型是中性、真空、PBE，不含溶剂、电位或有限温构型熵。

## 作业步骤

1. 按原子坐标核对层数、横向胞和覆盖度；列出固定原子。
2. 写一句可检验的问题、一个目标观测量、误差容限和最便宜的否定实验。
3. 分别列出数值误差与物理模型失效，不把软件设置清单当作研究问题。
4. 估算要算哪些独立参考，说明如何在 Slurm 分配资源与保存日志。

将回答写入自己的 `runs/01_calculation_memo/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。
