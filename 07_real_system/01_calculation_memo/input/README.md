# 输入说明

本项目在启动真实 H/Cu(111) 计算前，把研究问题、结构模型、参考态和判断标准写成一份可以据此安排作业的计算备忘录。

## 这些输入用于哪项任务

读取 clean.POSCAR、fcc.POSCAR 与 calculator.toml，核对原子数、层数、真空和固定原子。写出吸附反应、所需 H₂ 参考、0.05 eV 容限与优先收敛轴，并规划 Slurm 作业和日志归档。这里交付的是计算设计及理由。

## 阅读文件前先核对一个具体例子

1×1 Cu(111) 表面胞每层有一个表面位点，放一个 H 对应 1 ML。若原计划讨论低覆盖度孤立吸附，这套输入已经改变了所问问题，不能等结果出来再补一句“使用小胞”。

吸附能需要含 H 表面、清洁表面、H₂ 三个参考。只完成含 H 表面的一个总能，即使它已电子收敛，也还没有得到吸附反应的能量。
