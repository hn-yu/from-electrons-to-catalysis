# 03 · 保留真正的事前与事后记录

本项目学习保留事前判断，并用事后结果更新它；对已有公开数据做历史审查，对尚未执行的新计算才写新的盲预测。

## 背景：为什么需要这一步

人在看到结果后很容易重新组织理由，让原本意外的结果显得“早就知道”。事前记录把当时的预期、置信度和失败标准固定下来，让结果能检验我们的理解，而不只是被动配上解释。

预测可以是区间、符号或趋势，不要求凭空猜准很多小数。它应该明确到足以影响决策：如果区间同时覆盖正负吸附能，就不能以结果落在区间内宣称已经预测对吸附方向。数值收敛容限则是另一项更具体的判断。

本仓库已公开历史计算，所以读者不能再对它们声称不知结果。练习应先评价原始记录，再选自己尚未计算的新条件，保留预测并在真实运行后追加测量。

## 开始前需要理解的概念

- **事前预测**：在看到目标结果前记录的预期和理由。
- **置信度**：对预测可靠程度的自我评估，不等于数值求解容差。
- **postmortem**：看到结果后的复盘，应作为追加条目保留时间身份。
- **区间覆盖与判别力**：宽区间容易覆盖结果，却可能无法支持所需决策。

## 本次任务：从什么得到什么

阅读 historical-prediction.md，区分原始区间与追加复盘。评价它能否判断吸附符号和厚度收敛，再复制 prediction-template.md 为新的 5/6 层等未执行计算填写理由、预期、容限和失败标准；测量栏留到实际完成后填写。

## 先用一个小例子走通思路

历史区间为 −0.8 到 +0.3 eV，它覆盖了当前正负两种吸附能。结果落在其中只能说明区间未被排除，不能证明预测了符号，也不能证明三层与四层差小于 0.05 eV。

新的预测应具体说出“保持哪些条件、改变几层、希望差值落在哪个范围、什么结果需要改模型或继续加层”。若结果不符，保留原条目，再追加原因和下一项检验。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

- [prediction-template.md](input/prediction-template.md)

- [historical-prediction.md](input/historical-prediction.md)

历史区间：$E_{ads}\in[-0.8,+0.3]$ eV，低置信度。容限：0.05 eV。区间覆盖度与数值收敛是两个不同命题。

```math
\Delta_{layers}=E_{ads}^{4L}-E_{ads}^{3L}.
```

不要用已知的 Δlayers 来伪造一条声称更早写下的精确预测。

## 作业步骤

1. 阅读 input/historical-prediction.md，分别识别原始预测与追加的 postmortem。
2. 评价这个区间能回答“吸附符号是否可靠”吗？
3. 为 5/6 层的未执行实验填 prediction-template.md，给出物理理由、容限和失败标准。
4. 说明如何保留原条目，再追加实际测量；没有计算时不得填写测量值。

将回答写入自己的 `runs/03_blind_prediction/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。
