# 输出说明

本项目学习保留事前判断，并用事后结果更新它；对已有公开数据做历史审查，对尚未执行的新计算才写新的盲预测。

## 应先读什么、回答什么

先完成历史审查和自己的新预测，再读 output/answer.md。完成后应能辨认一项记录到底是在预测、测量还是事后解释，并用失败结果真实地更新下一轮计划。

## 用于理解这些结果的背景

人在看到结果后很容易重新组织理由，让原本意外的结果显得“早就知道”。事前记录把当时的预期、置信度和失败标准固定下来，让结果能检验我们的理解，而不只是被动配上解释。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
