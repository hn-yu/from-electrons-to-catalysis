# 输入说明

本项目审查“算一条迁移路径就能解释催化活性”的研究提案，把路径存在、事件发生和控制观测量拆成分别需要证据的命题。

## 这些输入用于哪项任务

读取 observation.csv 的温度和观察时间，用 κ=1 的单步 TST 反演势垒量级。将提案拆为四个命题，各列出最便宜的否定检查；最后选择不超过三项下一步计算，说明它们分别减少哪种不确定性。

## 阅读文件前先核对一个具体例子

若一个已经被占据的初态以常数 k 发生单步事件，等待时间均值为 τ=1/k。把 TST 公式反解，可得到目标 τ 对应的 ΔG‡；对数里的 $(k_BT/h)\tau$ 必须无量纲。

但若表面只有极少人口处于该初态，即使它一旦被占据就迅速跳跃，宏观事件数仍可能很少。若要进一步解释扩散或 TOF，还要加入跳长、网络连接和覆盖度，而不是只用这个反演势垒。
