# 05 · 对“算一个 NEB 就证明迁移”进行答辩

本项目审查“算一条迁移路径就能解释催化活性”的研究提案，把路径存在、事件发生和控制观测量拆成分别需要证据的命题。

## 背景：为什么需要这一步

一条低势垒路径只说明给定模型中存在某个通道。初态是否有足够人口、竞争反应是否先发生、跳跃是否在观测时间内可见，以及该过程是否影响总产物通量，都需要额外信息。

从实验问题反推计算时，可以先用温度和观测时间估计相关单步势垒尺度，再检查端点稳定性、占据和竞争逃逸。这些低成本判断有时比立即加密一条已有 NEB 更能改变研究决策。

本项目是一份有计算依据的提案审查，不是要求用语言否定所有机制。目标是保留可检验的核心假设，明确什么结果会支持它、什么结果会使我们放弃或修改它，并给出有限的后续工作。

## 开始前需要理解的概念

- **路径存在**：势面上找到连接，不等于体系频繁访问该通道。
- **可观测时间**：实验或模拟能等待多久，为相关事件率提供尺度。
- **竞争逃逸**：初态还可能经其他路径离开，改变目标事件的概率。
- **控制 TOF**：改变该过程会显著改变整体稳态通量，需要网络与人口证据。

## 本次任务：从什么得到什么

读取 observation.csv 的温度和观察时间，用 κ=1 的单步 TST 反演势垒量级。将提案拆为四个命题，各列出最便宜的否定检查；最后选择不超过三项下一步计算，说明它们分别减少哪种不确定性。

## 先用一个小例子走通思路

若一个已经被占据的初态以常数 k 发生单步事件，等待时间均值为 τ=1/k。把 TST 公式反解，可得到目标 τ 对应的 ΔG‡；对数里的 $(k_BT/h)\tau$ 必须无量纲。

但若表面只有极少人口处于该初态，即使它一旦被占据就迅速跳跃，宏观事件数仍可能很少。若要进一步解释扩散或 TOF，还要加入跳长、网络连接和覆盖度，而不是只用这个反演势垒。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

- [observation.csv](input/observation.csv)

```math
\Delta G^\ddagger=k_BT\ln\left[\frac{k_BT}{h}\tau\right],
```

这是 κ=1 的单步 TST 反演，只用于已占据初态的平均等待时间。宏观扩散还取决于跳长、网络与相关性；催化活性还取决于人口与反应通量。

## 作业步骤

1. 将“存在路径”“主导微观跳跃”“实验时间内可见”“控制 TOF”拆成四个命题。
2. 根据 input/observation.csv 的温度与观察时间，反推可见单步势垒量级。
3. 对每个命题列出最便宜的否定实验，包括端点稳定性和竞争逃逸。
4. 提出不超过三项的下一步计算，并说明每项为什么比直接加密 NEB 更有决策价值。

将回答写入自己的 `runs/05_advisor_defense/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。
