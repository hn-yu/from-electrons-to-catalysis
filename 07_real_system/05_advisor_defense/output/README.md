# 输出说明

本项目审查“算一条迁移路径就能解释催化活性”的研究提案，把路径存在、事件发生和控制观测量拆成分别需要证据的命题。

## 应先读什么、回答什么

先写自己的四命题审查和三项计划，再读 output/answer.md。完成后应能把一个宽泛机制故事收敛为可执行、可被结果改变的计算问题，并说明目前证据支持到哪一层。

## 用于理解这些结果的背景

一条低势垒路径只说明给定模型中存在某个通道。初态是否有足够人口、竞争反应是否先发生、跳跃是否在观测时间内可见，以及该过程是否影响总产物通量，都需要额外信息。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
