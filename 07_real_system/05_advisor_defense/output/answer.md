# 参考分析


首先优化端点，核对相同化学计量、自旋、晶胞和约束，并检查相关曲率。若终态松弛回初态，原提案并未定义两个亚稳态。

其次检查起点在给定化学势下的人口与竞争陷阱。即使 Y 路径低势垒，起点几乎从不被占据时它也可能不影响实验。单条平滑 NEB 只给指定势面上的候选路径，仍需检查替代初始路径和鞍点模式。

600 K 下，1 μs 等待时间对应约 0.845 eV 的 TST 自由能势垒，1 s 约 1.559 eV。1 ps 无偏轨迹不能排除微秒过程；有偏轨迹频繁跨越也不能直接当无偏速率。

最低能量路径缺少横向熵与可能的隐藏慢变量。表观活化能还包含覆盖度和机制响应，因此一般不等于一条 NEB 势垒。

建议的三项是：端点与低成本竞争陷阱检查；决定初态人口的自由能/储库计算；在这些通过后进行多初始路径 NEB 和鞍点验证。若目标是 TOF，再将通道嵌入详细平衡网络并计算灵敏度。
