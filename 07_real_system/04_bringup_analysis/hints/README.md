# 怎样使用本项目的提示

本项目重新分析真实 PBE 能量表，找出当前吸附结论最受哪项误差影响，并据此安排下一轮计算。

## 先明确你正在解决的任务

用 cases.csv 和 energies.csv 独立重建吸附能与每轴差值，按原定 0.05 eV 判据作结论。分别解释厚度导致的符号变化和横向胞导致的覆盖度变化，再提出保持物理条件一致的后续厚度序列，写入 answer.md。

打开提示前，先尝试解释下面这个例子；如果概念还不清楚，回到 [正文背景](../README.md)，然后再写局部代码或答案。

厚度差约为 $-0.30182-0.04560=-0.34742$ eV，其绝对值约为容限的七倍。此时把报告写成“多数参数已经稳定”会遗漏决定吸附符号的关键失败。

若继续计算 4/5/6 层，应同时说明固定层策略、覆盖度、k 点等如何保持可比，以及需要怎样的平台趋势才能更新当前未收敛判断。不能在看到新差值后再移动标准。

## 按推理顺序打开

1. [重新算差值，而不照抄结论](hint1.md)
2. [把覆盖度轴单独解释](hint2.md)
3. [下一步取决于最弱的推断](hint3.md)

## 用结果检验理解

先检查自己重算的每个差值，再与 output/answer.md 的证据和优先级比较。完成后应能从失败结果提出有限且可检验的下一步，而不是笼统要求所有参数都更大。
