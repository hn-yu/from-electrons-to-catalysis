# 输出说明

本项目重新分析真实 PBE 能量表，找出当前吸附结论最受哪项误差影响，并据此安排下一轮计算。

## 应先读什么、回答什么

先检查自己重算的每个差值，再与 output/answer.md 的证据和优先级比较。完成后应能从失败结果提出有限且可检验的下一步，而不是笼统要求所有参数都更大。

## 用于理解这些结果的背景

一次初步计算完成后，最有价值的问题通常是“哪个判断已经被结果改变”。如果原假设是所有数值变体都在容限内，某个轴的大变化就足以否定它；其他轴的小变化不能通过平均把这个失败消去。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
