# 04 · 失败的收敛假设怎样产生下一步

本项目重新分析真实 PBE 能量表，找出当前吸附结论最受哪项误差影响，并据此安排下一轮计算。

## 背景：为什么需要这一步

一次初步计算完成后，最有价值的问题通常是“哪个判断已经被结果改变”。如果原假设是所有数值变体都在容限内，某个轴的大变化就足以否定它；其他轴的小变化不能通过平均把这个失败消去。

复盘需要回到目标量和控制变量。总能可能随系统大小变化很多，但反应能差也可能抵消；横向扩胞则可能同时改变覆盖度，必须将它从纯数值精度讨论中分辨出来。

下一轮计算应减少当前主导不确定性。若连吸附态的相对稳定性都对 slab 厚度敏感，立即计算复杂 NEB 会把未解决的误差带进更多结果。先建立稳定参考，才便于解释之后的路径和速率。

## 开始前需要理解的概念

- **误差预算**：围绕目标观测量分别记录各来源的变化与已知限制。
- **主导不确定性**：当前最可能改变科学判断、且尚未受控的因素。
- **单因素差值**：变体目标量减基准目标量，保留符号与大小。
- **后续计算价值**：结果是否能够排除或支持一个当前仍悬而未决的判断。

## 本次任务：从什么得到什么

用 cases.csv 和 energies.csv 独立重建吸附能与每轴差值，按原定 0.05 eV 判据作结论。分别解释厚度导致的符号变化和横向胞导致的覆盖度变化，再提出保持物理条件一致的后续厚度序列，写入 answer.md。

## 先用一个小例子走通思路

厚度差约为 $-0.30182-0.04560=-0.34742$ eV，其绝对值约为容限的七倍。此时把报告写成“多数参数已经稳定”会遗漏决定吸附符号的关键失败。

若继续计算 4/5/6 层，应同时说明固定层策略、覆盖度、k 点等如何保持可比，以及需要怎样的平台趋势才能更新当前未收敛判断。不能在看到新差值后再移动标准。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

- [cases.csv](input/cases.csv)
- [energies.csv](input/energies.csv)

输入 `energies.csv` 与 `cases.csv` 包含真实 PBE 的基准及变体。独立重算

```math
E_{ads}=E_{total}-E_{clean}-E_{H_2}/2.
```

对每个轴记录相对基准差，不只记录“通过/失败”。横向扩胞还改变覆盖度，属于不同物理条件。

## 作业步骤

1. 重建每个吸附能与相对基准变化，指出最大差来自哪个轴。
2. 对照 0.05 eV 阈值评估“全部变化均在容限内”的命题。
3. 解释三层与四层符号相反如何影响原吸附假设。
4. 提出一个比立即做 NEB 更能减少当前主导不确定性的计算序列。

将回答写入自己的 `runs/04_bringup_analysis/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。
