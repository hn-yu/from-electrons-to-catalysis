# 05 · 电子能、自由能与储库的检查点

本项目把电子能、振动和气体储库项整理成一份不会漏算或重复计数的反应自由能账本。

## 背景：为什么需要这一步

热力学错误常发生在连接两个正确计算时：电子结构表给出总能，热化学表给出修正，气体化学势又可能已经包含这些修正。若不先写明每列的定义，简单相加就可能把某一项算两遍。

这里不需要新求解器，而需要先写反应式，再按“产物减反应物”逐项分解。每个电子能、ZPE、热焓、熵和压力项都应有明确归属。完成这样的账本后，改变标准态或温度才有可追踪的影响。

## 开始前需要理解的概念

- **反应量 ΔX**：按化学计量数求产物与反应物之差。
- **热修正**：从指定电子能参考补到目标热力学量的部分，需说明是否已包含 ZPE。
- **标准化学势 μ°**：标准压力下的每粒子 Gibbs 自由能，可能已经包含全部分子热化学。
- **抵消**：同一约定下相同贡献在反应差中消去，需要逐项证明。

## 本次任务：从什么得到什么

读取 thermochemistry.csv，为气相分子写 H/S/G 分项，再写吸附反应的 ΔG。用 600 K 的压力变化和 CO₂/H₂O 模式计数检查自己的账本，提交带公式、数值与近似范围的 answer.md。

## 先用一个小例子走通思路

如果使用 $\mu_{gas}=E_{gas}+ZPE_{gas}+\Delta H_{gas}-TS_{gas}$，则在吸附自由能中减去 μgas 时，气体 ZPE 已经被减去一次；再单独减 ZPEgas 会重复计数。

600 K 时压力提高十倍，单个理想气体粒子的 μ 增加约 0.11905 eV。反应消耗一个气体粒子时，反应自由能降低这个量；若反应产生两个，压力贡献则增加两倍这个量。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

- [thermochemistry.csv](input/thermochemistry.csv)

```math
\Delta G(T,p)=\Delta E_{elec}+\Delta ZPE+\Delta H_{thermal}-T\Delta S,
```

```math
\mu(T,p)=\mu^\circ(T)+k_BT\ln(p/p^\circ).
```

若 μ° 已经包含气体 ZPE 与热修正，反应式中不能再重复加入这些气体项。

## 作业步骤

1. 读取 input/thermochemistry.csv，解释每一列进入 H、S、G 的位置。
2. 对 600 K、压力增加十倍，手算气体 μ 变化与吸附 ΔG 的变化方向。
3. 写出线性 CO₂ 和非线性 H₂O 应有的内部模式数及旋转对称数。
4. 给出一种电子吸附能负、自由吸附能正的温压条件，并声明使用的近似。

将回答写入自己的 `runs/05_checkpoint/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。
