# 输出说明

本项目把电子能、振动和气体储库项整理成一份不会漏算或重复计数的反应自由能账本。

## 应先读什么、回答什么

先完成自己的自由能分项表，再读 output/answer.md。完成后应能审核别人给出的吸附自由能公式，指出参考态、气体计量数和是否重复加入热修正。

## 用于理解这些结果的背景

热力学错误常发生在连接两个正确计算时：电子结构表给出总能，热化学表给出修正，气体化学势又可能已经包含这些修正。若不先写明每列的定义，简单相加就可能把某一项算两遍。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
