# 外部资料链接的检查

外部参考应指向与正文对应的官方教程或 API 章节。更新链接时，先从官方网站的目录找到目标，核对标题和内容，再验证网页与 `#` 后的章节锚点；仅能打开软件首页不足以替代具体资料。

## 运行检查

从仓库根目录运行，Python 3.11 标准库即可，不需要安装计算化学依赖：

```bash
python3 scripts/check_external_links.py --report runs/external-links.json
```

脚本扫描 Git 跟踪及未被忽略的新 Markdown、RST 和 HTML 文档，合并重复地址后发送 GET 请求。报告保留每个引用的文件和行号、HTTP 状态、跳转后的地址、页面标题和锚点检查结果。目的地址中的空格或字面括号应使用 URL 百分号编码。

HTTP 错误、超时、返回错误页面标题的 HTTP 200、以及不存在的 HTML 锚点都会令检查失败。暂时性网络错误会重试；检查不会把失败地址列入忽略名单。更换地址之后仍需人工确认引用内容与正文相符。

## 自动检查

[external-links 工作流](../.github/workflows/external-links.yml) 在文档变更、每周一及手动触发时执行。每次运行保存 `external-links` 检查报告，失败时日志会指出具体文件和行号。

外链检查与数值测试独立，因为外部文档即使在本仓库没有新提交时也会迁移。原有 [项目检查](../scripts/check_projects.py) 继续验证本地路径与计算输入、输出的追溯关系。
