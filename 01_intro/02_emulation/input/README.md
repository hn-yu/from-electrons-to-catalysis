# 输入说明

本项目设计一条从简单势函数到真实电子结构软件的学习路线：哪些步骤可以先用便宜模型调通，哪些结论必须等到目标模型上才能检查。

## 这些输入用于哪项任务

阅读 contracts.csv，为力、SCF、DFT 和动力学分别写下“自己实现的核心、直接使用的库、独立对照固定的条件”。然后选择 H₂ 的一次小位移，设计先检查单点能量与力、再进入优化的顺序。交付一张包含检查对象和失败含义的工作表。

## 阅读文件前先核对一个具体例子

假设自写 Verlet 与 ASE 在同一个 LJ 势上产生相同轨迹，这支持积分器和单位接口的一致性。若随后把势换成 EMT，轨迹变了，这首先意味着运动方程的力变了，而不是 Verlet 突然失效。

类似地，EMT 与 PBE 在一个结构上恰好给出接近的吸附能，不表示它们在其他坐标、位点或过渡态上也相同。必须保持比较层次清楚，才能知道下一次差异应从哪里排查。
