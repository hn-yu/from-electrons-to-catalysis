# 输出说明

本项目设计一条从简单势函数到真实电子结构软件的学习路线：哪些步骤可以先用便宜模型调通，哪些结论必须等到目标模型上才能检查。

## 应先读什么、回答什么

参考 answer.md 给出的是一种合理的迁移顺序。检查你的工作表是否能为每种失败指出下一步：力符号错回到导数，k 点敏感回到周期积分，目标电子态不合理则回到物理模型。不能把三者都写成“增加计算精度”。

## 用于理解这些结果的背景

原子模拟中，很多算法只向外询问两件事：当前构型的能量是多少，每个原子受到什么力。它们可以把能量来源看成一个接口，而不必知道内部是解析函数、经验势，还是一次电子自洽计算。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
