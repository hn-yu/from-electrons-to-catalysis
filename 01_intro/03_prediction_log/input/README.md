# 输入说明

本项目练习在计算前提出一个可以被结果改变的判断，并在计算后保留原判断。你要建立的是科学记录，而不是猜中一个已经公布的答案。

## 这些输入用于哪项任务

在 prediction-template.md 的副本中选择一个未测条件，填写固定条件、唯一扰动、预期变化及理由。先保存这一版，再执行相应计算，最后追加测量与后续决策。若暂时不运行计算，就把测量栏留空，并说明需要什么证据。

## 阅读文件前先核对一个具体例子

旧 H/Cu 预测区间为 −0.8 到 +0.3 eV，低置信度。三层的 +0.0456 eV 和四层的 −0.3018 eV 都在区间内，但二者的符号相反、差约 0.35 eV。因此“落入预测区间”和“已经判断出吸附有利”是不同结论。

更有用的下一条预测可以针对加厚是否产生稳定平台，并明确覆盖度和误差阈值。它会直接改变下一轮计算选择。
