# 输出说明

本项目练习在计算前提出一个可以被结果改变的判断，并在计算后保留原判断。你要建立的是科学记录，而不是猜中一个已经公布的答案。

## 应先读什么、回答什么

你的结果是填好的预测记录及后续决策。阅读参考分析时，检查自己有没有把“知道结果之后的解释”混进事前栏。完成标准是能看见一次判断如何被证据更新，而不是与参考答案使用同一句话。

## 用于理解这些结果的背景

计算化学有许多可调设置，结果出现后往往容易找到一个听起来合理的解释。如果没有事前记录，就很难分辨哪些认识真正在实验中获得支持，哪些只是看过结果后的重述。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
