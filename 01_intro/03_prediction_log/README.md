# 03 · 把预测写成可以被结果改变的判断

本项目练习在计算前提出一个可以被结果改变的判断，并在计算后保留原判断。你要建立的是科学记录，而不是猜中一个已经公布的答案。

## 背景：为什么需要这一步

计算化学有许多可调设置，结果出现后往往容易找到一个听起来合理的解释。如果没有事前记录，就很难分辨哪些认识真正在实验中获得支持，哪些只是看过结果后的重述。

预测不必是精确数字。一个变化方向、数量级、区间或“目前还不能判断符号”的声明，都可以有价值，前提是条件和否定证据明确。它的作用是决定计算预算：什么结果出现时继续加厚 slab，什么结果出现时应改变机制或参考态。

后面的 H/Cu 数据已经公开，因此在这里把其数值重新写进模板不算盲预测。它可以作为回顾案例；真正的新预测必须针对你尚未查看或尚未执行的扰动。

## 开始前需要理解的概念

- **观测量**：先明确要预测的是总能、吸附能、自由能还是速率，以及每原子/每位点的归一化。
- **预测区间**：区间应对应某个用途；跨过零的吸附能区间通常不能确定吸附符号。
- **容限**：对数值稳定性的事前要求，与对真实物理量的预测区间不同。
- **事后分析**：允许改变认识，但应追加理由和证据，不覆盖原预测。

## 本次任务：从什么得到什么

在 prediction-template.md 的副本中选择一个未测条件，填写固定条件、唯一扰动、预期变化及理由。先保存这一版，再执行相应计算，最后追加测量与后续决策。若暂时不运行计算，就把测量栏留空，并说明需要什么证据。

## 先用一个小例子走通思路

旧 H/Cu 预测区间为 −0.8 到 +0.3 eV，低置信度。三层的 +0.0456 eV 和四层的 −0.3018 eV 都在区间内，但二者的符号相反、差约 0.35 eV。因此“落入预测区间”和“已经判断出吸附有利”是不同结论。

更有用的下一条预测可以针对加厚是否产生稳定平台，并明确覆盖度和误差阈值。它会直接改变下一轮计算选择。

## 这个项目应该自己完成什么

本项目要求**手写推理、量纲检查和可否定的判断**。引用前面计算项目的成熟软件结果；不把讨论题包装成返回 true/false 的脚本。必要算术可以使用 NumPy，电子结构、采样与动力学仍由对应项目的软件完成。

## 输入案例

若预测区间为 $[L,U]$，一次结果 y 落在区间内并不能证明模型准确。区间越宽，越容易覆盖结果，但决策价值越低。


## 作业步骤

1. 阅读 prediction-template.md，为一个尚未查看输出的扰动写事前预测。
2. 必须列出目标观测量、单位、固定条件、区间或变化符号、理由、失效证据。
3. 单独追加测量与事后解释，禁止覆盖原预测。
4. 对已经公开的 H/Cu 示例只能做回顾分析；选择新层数、覆盖度或扰动作为下一次预测。

将回答写入自己的 `runs/03_prediction_log/answer.md`，保留输入数据、公式、计算出的数值与结论范围。先完成回答，再查看 [参考分析](output/answer.md)。历史回答保存在 output/previous-answer.md；其中事前预测与事后测量不能互换身份。

## 完成后应能解释什么

你的结果是填好的预测记录及后续决策。阅读参考分析时，检查自己有没有把“知道结果之后的解释”混进事前栏。完成标准是能看见一次判断如何被证据更新，而不是与参考答案使用同一句话。
