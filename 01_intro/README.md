# 01 · 我们怎样从电子问题走向化学判断

这一章先定义整门课在做什么：给定原子核、电子数和环境，用一个明确的物理模型计算能量，再逐步讨论结构、平衡和反应。暂时不要求写电子结构求解器；先把计算对象、近似和证据关系讲清。

## 为什么先从这里开始

“某个分子吸附得强”“某个反应很快”“某个催化剂活性高”是不同问题。吸附强弱涉及指定参考态的能量或自由能差，快慢涉及跨越能垒，催化活性还取决于表面上有多少反应物以及多个步骤如何耦合。

它们共同的微观起点是电子与核的相互作用。Hamiltonian 给出量子问题；Born–Oppenheimer 近似把固定核的电子问题与核运动分开，得到核坐标的势能面。后续算法都是在这个基础上增加表示、近似或统计描述。

本章还建立一种工作方式：用便宜且可解的模型检查算法，用成熟软件完成复杂电子结构，再用事前预测和受控实验检查结论。每种证据都有明确适用范围。

## 开始时需要会什么

能读原子坐标、做简单代数和单位换算即可。波函数、算符和势能面会在第一项解释；无需预先掌握 HF、DFT 或统计力学。若不熟悉导数，可先理解它表示“位置略变时能量怎么变”，下一章再实际计算。

## 用 H₂ 贯穿这三个问题

XYZ 中 0.74 Å 的核距只指定了两个核的位置。原子单位下，核排斥为

```math
E_{NN}=rac{Z_1Z_2}{R_{12}}\approx0.7151\ \mathrm{Hartree}.
```

这里 R 必须先换成 bohr。这个数可以手算，但它不是分子总能；电子态仍待求解。稍后你会用简单 Morse 势理解键的形状，再用 PySCF 积分和自己的 RHF 求电子近似。

如果两套 RHF 程序相符，支持的是实现一致性；如果换方法后拉伸曲线改变，讨论的是物理近似；若核距换算错，则问题更早就发生在输入。预测记录帮助你事前说清自己要检验哪一种差异。
