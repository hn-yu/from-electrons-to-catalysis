# 输入文件、格式与单位

从 [项目正文](../README.md) 的物理模型开始。`run.py --input` 接收本目录的副本，而不是一个 JSON 文件。

## [H2_0.74.xyz](H2_0.74.xyz)

分子原子坐标，Å；第一行原子数、第二行注释，之后元素与 x y z。

## [H2_1.50.xyz](H2_1.50.xyz)

## [O2.xyz](O2.xyz)

分子原子坐标，Å；第一行原子数、第二行注释，之后元素与 x y z。

## [control.toml](control.toml)

控制参数；字段中的 eV、A、K、bar 明确单位，数组仅表示扫描或软件设置。

## [geometries.csv](geometries.csv)

坐标文件索引；实际键长从 XYZ 重新计算，表中 bond_A 便于人工核对。

```csv
file,bond_A
H2_0.74.xyz,0.74
H2_1.50.xyz,1.5
```
