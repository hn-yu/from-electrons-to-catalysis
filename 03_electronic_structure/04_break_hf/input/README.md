# 输入说明

本项目使用已经成熟的 RHF/UHF 求解器，分别改变键长、自旋约束和基组，学习判断一个数值收敛的电子结构结果在物理上是否可信。

## 这些输入用于哪项任务

从 geometries.csv 指向的五个 H₂ XYZ 构建键长扫描，用 PySCF 独立求 RHF 和 UHF；另外在固定 O₂.xyz 上比较自旋设置，在固定 H₂ 几何上比较基组。自己负责控制变量、组织能量/S²/收敛表，并解释三个实验各检验什么。

## 阅读文件前先核对一个具体例子

纯单重态 H₂ 的 $S=0$，所以应有 $\langle S^2\rangle=0$。远距离破缺对称 UHF 若得到接近 1，虽然能量比 RHF 低，却没有得到一个纯单重态波函数。

如果只是把收敛阈值从较松改得更紧，S² 仍然接近 1，这不是提高迭代精度就能消除的误差。反过来，使用对称初猜可能让 UHF 留在 RHF 型解；“允许破缺”并不等于“已经找到破缺解”。
