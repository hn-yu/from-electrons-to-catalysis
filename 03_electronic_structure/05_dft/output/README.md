# 输出说明

本项目在相同几何和基组下比较 HF、几种密度泛函和 FCI，理解“更低的能量”“更多电子相关”与“更准确的预测”之间的区别。

## 应先读什么、回答什么

读每个方法的收敛标记、逐几何能量及相对 FCI 的差值。完成后应能把“提高积分网格”“增加基函数”“更换泛函”各自对应的误差来源写清，并解释为什么小分子上的一次排名不能直接推广到催化表面。

## 用于理解这些结果的背景

完整多电子波函数随电子数迅速变得复杂。密度泛函理论（DFT）改用三维电子密度作为基本变量；困难转移到了能量如何依赖密度。实际的 Kohn–Sham（KS）方法引入辅助的非相互作用轨道来计算动能，所以运行 DFT 时仍然会看到轨道、占据和 SCF 循环。
