# 怎样使用本项目的提示

本项目在相同几何和基组下比较 HF、几种密度泛函和 FCI，理解“更低的能量”“更多电子相关”与“更准确的预测”之间的区别。

## 先明确你正在解决的任务

读取 geometries.csv 中实际列出的 H₂ XYZ，在同一基组下调用 PySCF 的 RHF、RKS 与 FCI。手写方法比较表与相对能量分析：同一几何横向比较方法，固定方法纵向比较键长，再讨论误差随断键怎样变化。目录中的 O₂ 结构不属于这条闭壳层 H₂ 扫描。

打开提示前，先尝试解释下面这个例子；如果概念还不清楚，回到 [正文背景](../README.md)，然后再写局部代码或答案。

同一有限基组下，HF 的单行列式属于 FCI 的可变空间，因此 $E_{\rm FCI}\le E_{\rm HF}$。这给出了可以验证的不等式，也定义了该基组内的相关能。

近似 DFT 若低于 FCI，并不说明它突破了同一波函数变分下界：它计算的是另一个近似能量表达式。比较解离行为时，还要看拉伸后的能量变化是否合理，不能只检查平衡点的绝对误差。
