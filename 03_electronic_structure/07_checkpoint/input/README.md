# 输入说明

本项目把前面的电子结构结果当作待审核的证据，练习从输入、代数不变量、数值收敛和物理近似四个层面判断一个结论。

## 这些输入用于哪项任务

读取给定水分子的 scf-report.txt，结合前面项目的矩阵、HF 拉伸实验和周期收敛数据，写一份分层审核。每个判断都列出使用的数值或公式，以及失败时首先应修改的对象。交付物是自己的 answer.md，而不是又一次自动运行 SCF。

## 阅读文件前先核对一个具体例子

水的中性体系有十个电子。如果自旋求和密度给出 $\mathrm{Tr}(DS)=5$，优先检查占据因子 2；把 SCF 阈值再收紧六位不能修复密度定义。

如果 Tr(DS)=10、残差也小，但拉伸 H₂ 的 RHF 曲线仍错误，则证据指向近似的适用性。相同的“能量不对”在两种情况下需要完全不同的处理。
