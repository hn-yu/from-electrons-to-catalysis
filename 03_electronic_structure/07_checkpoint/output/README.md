# 输出说明

本项目把前面的电子结构结果当作待审核的证据，练习从输入、代数不变量、数值收敛和物理近似四个层面判断一个结论。

## 应先读什么、回答什么

先完成自己的分层判断，再读 output/answer.md。完成后应能拿到陌生 SCF 报告后提出有顺序的检查，并说明哪些结论需要额外基组、方法或周期收敛数据。

## 用于理解这些结果的背景

计算软件输出很多位数字，但这些数字的可信度来自一串条件：电子数和几何设对了，矩阵约定一致，迭代和离散误差受控，选用的近似适合所问问题。某一层通过并不能替代其他层。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
