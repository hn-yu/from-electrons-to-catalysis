# 07 · 电子结构结果的四层核对

本项目把前面的电子结构结果当作待审核的证据，练习从输入、代数不变量、数值收敛和物理近似四个层面判断一个结论。

## 背景：为什么需要这一步

计算软件输出很多位数字，但这些数字的可信度来自一串条件：电子数和几何设对了，矩阵约定一致，迭代和离散误差受控，选用的近似适合所问问题。某一层通过并不能替代其他层。

检查点的目标是把零散公式变成诊断顺序。先做成本最低、结论最明确的检查，例如电子计数和单位；再看残差和收敛扫描；最后讨论模型在断键或周期材料中的适用性。这样才能区分需要改代码、改设置，还是改科学模型。

## 开始前需要理解的概念

- **不变量**：在选定约定下必须满足的关系，例如 Tr(DS)=电子数。
- **残差**：代回方程后的偏离；能量变化很小不总等于所有方程都满足。
- **数值收敛**：在固定模型中提高求解精度或表示精度。
- **方法检验**：用不同近似、可解极限或更可靠参照判断模型偏差。

## 本次任务：从什么得到什么

读取给定水分子的 scf-report.txt，结合前面项目的矩阵、HF 拉伸实验和周期收敛数据，写一份分层审核。每个判断都列出使用的数值或公式，以及失败时首先应修改的对象。交付物是自己的 answer.md，而不是又一次自动运行 SCF。

## 先用一个小例子走通思路

水的中性体系有十个电子。如果自旋求和密度给出 $\mathrm{Tr}(DS)=5$，优先检查占据因子 2；把 SCF 阈值再收紧六位不能修复密度定义。

如果 Tr(DS)=10、残差也小，但拉伸 H₂ 的 RHF 曲线仍错误，则证据指向近似的适用性。相同的“能量不对”在两种情况下需要完全不同的处理。

## 输入案例

- [scf-report.txt](input/scf-report.txt)

RHF 的关键不变量是

```math
\mathrm{Tr}(DS)=N_e,\quad X^TSX=I,\quad FDS-SDF\rightarrow0,
```

```math
E_{tot}=\tfrac12\mathrm{Tr}[D(H+F)]+E_{NN}.
```

这些关系检验算法的一致性；UHF 的 $\langle S^2\rangle$、有限基组 FCI 与周期收敛趋势检验的是其他层次。
