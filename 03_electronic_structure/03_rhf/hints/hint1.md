# 提示 1：先让输入确实成为你想要的张量

`eri.dat` 的一行 `1 2 1 1 value` 表示 $(12|11)$，文件指标从 1 开始；数组指标从 0 开始。先减 1，再写数组。若输入只给非零唯一积分，没读到的元素应保持零，不能是未初始化内存。

对一行 $(ij|kl)$，恢复

$$
(ij|kl)=(ji|kl)=(ij|lk)=(ji|lk)
=(kl|ij)=(lk|ij)=(kl|ji)=(lk|ji).
$$

这不包含任意的四指标置换。例如 $(12|12)$ 不必等于 $(11|22)$。前者与轨道重叠乘积有关，后者对应两个电子密度之间的库仑相互作用。

先用小数组验证，再进入 SCF：

```python
eri = np.zeros((n, n, n, n))
for a, b in [(i, j), (j, i)]:
    for c, d in [(k, l), (l, k)]:
        eri[a, b, c, d] = value
        eri[c, d, a, b] = value
```

四阶完整张量只适合小体系。一般 $n^4$ 个 double 需要 $8n^4$ 字节；100 个 AO 已约 800 MB。这个量级说明为什么成熟量子化学软件要考虑直接 SCF、密度拟合、壳层筛选与分布式存储，但本项目先解决小体系的正确性。

检查：`S == S.T`、`h == h.T`、上述 ERI 置换相等。还可以直接与 `mol.intor('int2e')` 比对，借此区分“文件重建错”和“SCF 错”。
