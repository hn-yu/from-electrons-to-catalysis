# 提示 2：正交化为什么不是矩阵元的开方

假设 $S=UsU^T$ 且 U 正交。则

$$
X^TSX=(Us^{-1/2}U^T)(UsU^T)(Us^{-1/2}U^T)=I.
$$

这个恒等式依赖谱分解，逐元素 `S**(-0.5)` 没有这样的性质，遇到负的非对角矩阵元还会产生无意义值。

```python
s, U = np.linalg.eigh(S)       # U 的列是本征矢
X = (U / np.sqrt(s)) @ U.T    # 按列缩放 U
Fprime = X.T @ F @ X
eps, Cprime = np.linalg.eigh(Fprime)
C = X @ Cprime
```

依次检查 `X.T @ S @ X` 与 `C.T @ S @ C`。如果第一个失败，先不要研究密度或能量。若第二个失败而第一个通过，检查回变换是否误用了 `X.T` 或重复变换。

为什么近线性相关危险？若 $s_{min}=10^{-12}$，相应方向乘上 $10^6$；微小积分噪声会被放大。删除这个方向是一种模型/基组处理选择，需要记录阈值，而不是把负本征值取绝对值后继续。
