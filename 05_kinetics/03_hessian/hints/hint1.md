# 提示 1：原子指标与 Cartesian 指标要交错

PySCF 返回 $H_{AB\alpha\beta}$，其中 A、B 是原子，α、β 是 x/y/z。需要的二维矩阵是 $H_{(A\alpha)(B\beta)}$。所以顺序变换是

```python
H2d = H4d.transpose(0, 2, 1, 3).reshape(3*N, 3*N)
```

若直接 reshape，矩阵可能仍然含 81 个数，但行列不再对应同一个 Cartesian 坐标排列。错误不一定通过矩阵大小暴露。

把一个简单元素展开：第 1 个原子的 y 与第 2 个原子的 z，对应零起点的 `H4d[0, 1, 1, 2]`，应进入 `H2d[1, 5]`。先写三个这样的索引测试，再进行对角化。

同时检查 $H=H^T$。若由力差分获得 H，反对称部分的大小是数值误差诊断；先打印它，再考虑使用 $(H+H^T)/2$，不要用对称化掩盖错误的索引。
