# 06 · 从力到速率，哪一步证明了什么

本项目审核“力很小 → 找到过渡态 → 知道反应速率”这条推断链，指出每一步已有证据和仍缺的物理信息。

## 背景：为什么需要这一步

优化器、频率分析、NEB 和 TST 分别求解不同问题：找驻点、判断局部曲率、寻找连接路径、估计跨越事件率。把它们按顺序运行并不会自动证明真实反应机制，因为每次转换都增加了假设。

本检查点要求把“计算得到什么”和“据此能推断什么”写在一起。例如一个小负频率可能来自刚体数值误差，一个真正负模也要检查是否连接目标反应盆地；势能剖面再漂亮，也不能自动代替有限温自由能。

## 开始前需要理解的概念

- **驻点分类**：结合一阶导数与相关自由度中的负曲率数目。
- **路径连接性**：候选山口两侧是否通向所问初态和终态。
- **势垒类型**：电子势能差与自由能差有不同的统计内容。
- **时间尺度与扩散系数**：后者还需要跳跃长度、方向数和相关性等信息。

## 本次任务：从什么得到什么

用给定 normal_modes.csv 判断水的近零模式，构造“受力为零但不是最低点”的反例，手算势垒误差的速率倍率，并为从二维 NEB 迁移到真实表面扩散列出缺失输入。把证据链写入自己的 answer.md。

## 先用一个小例子走通思路

二维 $E(x,y)=x^2-y^2$ 在原点梯度为零，但 Hessian 本征值一正一负，所以是鞍点。再严格的力阈值也不能把它变成极小值。

即使该模型给出一个明确势垒，坐标还没有对应实际原子位移和长度，因而不能直接得到以 m²/s 表示的扩散系数。这个缺口属于物理映射，不能靠多输出几位能量解决。

## 输入案例

- [normal_modes.csv](input/normal_modes.csv)

驻点满足 $\nabla E=0$；局部极小值要求相关自由度的 Hessian 无负曲率；一阶鞍点应有一个相关负曲率方向。

```math
k\approx\frac{k_BT}{h}e^{-\Delta G^\ddagger/(k_BT)},\qquad \tau=1/k.
```

NEB 通常给势能势垒 ΔE‡，TST 需要指定状态和分割面的自由能势垒 ΔG‡。
