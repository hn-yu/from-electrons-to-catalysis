# 输出说明

本项目审核“力很小 → 找到过渡态 → 知道反应速率”这条推断链，指出每一步已有证据和仍缺的物理信息。

## 应先读什么、回答什么

先写自己的推断链，再与 output/answer.md 对照。完成后应能在一份路径计算报告中标出驻点、通道、自由能和动力学各自需要的验证，而不是仅以程序正常退出作为依据。

## 用于理解这些结果的背景

优化器、频率分析、NEB 和 TST 分别求解不同问题：找驻点、判断局部曲率、寻找连接路径、估计跨越事件率。把它们按顺序运行并不会自动证明真实反应机制，因为每次转换都增加了假设。

[answer.md](answer.md) 是基于输入案例的推导与有限结论。它是参考解，不是自动评分标准；不同结论需要相应证据支持。previous-answer.md 保留旧版本与历史预测，避免把现在知道的结果伪装成事前判断。
