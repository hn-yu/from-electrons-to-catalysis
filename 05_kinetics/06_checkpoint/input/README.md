# 输入说明

本项目审核“力很小 → 找到过渡态 → 知道反应速率”这条推断链，指出每一步已有证据和仍缺的物理信息。

## 这些输入用于哪项任务

用给定 normal_modes.csv 判断水的近零模式，构造“受力为零但不是最低点”的反例，手算势垒误差的速率倍率，并为从二维 NEB 迁移到真实表面扩散列出缺失输入。把证据链写入自己的 answer.md。

## 阅读文件前先核对一个具体例子

二维 $E(x,y)=x^2-y^2$ 在原点梯度为零，但 Hessian 本征值一正一负，所以是鞍点。再严格的力阈值也不能把它变成极小值。

即使该模型给出一个明确势垒，坐标还没有对应实际原子位移和长度，因而不能直接得到以 m²/s 表示的扩散系数。这个缺口属于物理映射，不能靠多输出几位能量解决。
