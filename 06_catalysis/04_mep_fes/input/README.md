# 输入说明

本项目对同一个二维势分别做最小化和统计积分，直接展示最低能量路径与有限温自由能剖面为何不同。

## 这些输入用于哪项任务

读取温度表，对每个温度计算最低势能 V(x)、自己推导的 Gaussian 积分 F(x)，并用 SciPy quad 独立数值积分 y 核对。分别寻找各温度的自由能最低点，再比较势垒；不要固定使用零温最低点作为所有温度参考。

## 阅读文件前先核对一个具体例子

在 x=0 与 x=1，横向系数分别为 1 与 2。积分宽度之比为 $\sqrt2$，因此相对于 x=1，中央区域得到 $\tfrac12k_BT\ln2$ 的熵优势。

600 K 时这一项约 0.0179 eV，已能改变势垒。更精确的自由能势垒还要重新寻找 F 的极小值；它一般会偏离势能的 x=±1。

## [control.toml](control.toml)

控制参数；字段中的 eV、A、K、bar 明确单位，数组仅表示扫描或软件设置。
