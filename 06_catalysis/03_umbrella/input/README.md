# 输入说明

本项目通过多个带偏置的采样窗口探索能垒区域，再去除已知偏置恢复平衡自由能，理解采样覆盖和重加权各自解决什么问题。

## 这些输入用于哪项任务

从 windows.csv 读取 13 个中心与弹簧常数，用手写 Metropolis 生成并保存各窗口轨迹，丢弃初始平衡段。自己实现分箱 WHAM，再把同一批实际样本交给 PyMBAR FES；与解析边缘自由能比较，同时检查接受率、窗口重叠和隐藏坐标行为。

## 阅读文件前先核对一个具体例子

模型 $U(x,y)=0.15(x^2-1)^2+(1+x^2)y^2$ 在 x=0 附近的 y 分布比 x=±1 更宽。把 y 积分掉后，会多出 $\tfrac12 k_BT\ln(1+x^2)$，所以恢复的自由能不只是 y=0 上的势能。

若某个窗口从未访问某一 y 盆地，WHAM 和 PyMBAR 仍可能给出很接近的曲线，因为它们都在处理同一份缺失信息的数据。换初态、独立随机种子和更好的变量，是对此最直接的检查。

## [control.toml](control.toml)
