# 输入说明

本项目固定同一个正确的势函数，只改变计算导数的位移步长，观察误差如何先减小再增大。目标是学会选择数值参数，而不是记住一个通用步长。

## 这些输入用于哪项任务

从 bonds.xyz 读取实际距离，用解析式得到基准力。按 control.toml 扫描 50 个对数间隔步长，保存每次差分力误差，画 log–log 曲线。选几个位于误差谷底两侧的点，分别解释主导误差来源。

## 阅读文件前先核对一个具体例子

若某一段确实由二阶截断误差主导，把 h 减半应使误差约变为四分之一。继续缩小后这个规律失效，说明你已经进入舍入或噪声主导区。

给能量统一加很大的常数时，真实力仍然相同，但差分可能更差：计算机在两个更大的数之间寻找同样小的能量差。这个实验把“物理零点不影响力”与“数值表示影响差分”分开了。

## [bonds.xyz](bonds.xyz)

两原子构型，Å；多帧文件每一帧是独立距离案例。

## [control.toml](control.toml)

控制参数；字段中的 eV、A、K、bar 明确单位，数组仅表示扫描或软件设置。
