# 输入说明

本项目把电子结构、光谱和动力学中常见的单位放到同一个可检查的换算链上，并用热能尺度判断某个能量误差是否会影响结论。

## 这些输入用于哪项任务

逐行读取 conversions.csv，同时用自己的换算链和 ASE 常数换算同一个数。再读取温度表，输出每个温度的 kBT。你要提交换算过程、对照差值，以及对“0.1 eV 势垒误差有多大影响”的量级解释。

## 阅读文件前先核对一个具体例子

在 600 K，$k_BT\approx0.05170$ eV。若其他因素保持相同，将一个势垒提高 0.1 eV，速率之比是 $e^{-0.1/0.05170}\approx0.145$，即约慢七倍。

这个算术只使用一个指数比值，不要求你已经掌握完整 TST。它说明误差容限应围绕研究问题选择：允许速率差两倍与允许差十倍，对能量精度的要求不同。

## [control.toml](control.toml)

控制参数；字段中的 eV、A、K、bar 明确单位，数组仅表示扫描或软件设置。

## [conversions.csv](conversions.csv)

逗号分隔表；第一行为字段与单位，数值不可脱离列名解释。

```csv
value,from_unit,to_unit
1,eV,kJ/mol
1,Hartree,eV
```

## [temperatures.csv](temperatures.csv)

逗号分隔表；第一行为字段与单位，数值不可脱离列名解释。

```csv
T_K
300
600
```
