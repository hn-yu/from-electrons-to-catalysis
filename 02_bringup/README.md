# 02 · 先建立可信的单位、能量和力

这一章把核坐标变成程序可检查的能量与力。我们选择解析可解的模型，先把符号、方向、单位和数值误差弄清，再把同样接口接到电子结构软件。

## 为什么这些基础决定后面的结果

优化、动力学、振动和 NEB 都会反复调用能量/力接口。若力少了负号或 Å 与 bohr 混用，后续算法即使逐行正确，也会沿错误势面运行。最便宜的检查应尽早完成。

对所有原子坐标 R，力的定义是

```math
\mathbf F=-\nabla_{\mathbf R}E.
```

如果 E 使用 eV、坐标使用 Å，力就是 eV/Å。对两原子势 E(r)，还需要链式法则：先求能量对距离的导数，再沿两原子的连线分配方向。总平移不改变原子间距离，所以一对内部力应大小相同、方向相反。

解析导数、有限差分和成熟库提供三条互相补充的核对路径。有限差分自身也有误差，不是无条件正确的“标准答案”。

## 先预测一条误差曲线

中心差分为

```math
E'(x)\approx\frac{E(x+h)-E(x-h)}{2h}.
```

对光滑函数，截断误差通常随 h² 减小；但两次能量相减会放大舍入或能量噪声，其影响大致随 1/h 增长。因此扫描很多数量级的 h 时，常看到先改善、后恶化的误差曲线。

这条曲线会在后面反复出现：力差分构造 Hessian、压力导数给反应级数、能量微扰给速率控制。先在有解析答案的函数上理解它，才能为昂贵计算选择合理步长。
