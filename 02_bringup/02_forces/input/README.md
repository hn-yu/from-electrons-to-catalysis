# 输入说明

本项目把 XYZ 中两个原子的坐标转换为距离、能量和两原子的力。我们用可手工求导的 Morse 势，建立以后优化、振动和动力学共同依赖的接口。

## 这些输入用于哪项任务

读取 bonds.xyz 的每一帧，计算 r 和单位键向量。手写 Morse 能量及径向力，再转换成两行三分量原子力。对同一构型调用 ASE MorsePotential，并用能量中心差分检查导数。最终把三条路径在同一参数、距离和单位下对齐。

## 阅读文件前先核对一个具体例子

在 $r=r_e=0.74$ Å 时，本例能量为 −4.5 eV，力为零。将键拉长，力应把两个原子拉回；将键压短，力应把它们推开。

再把分子从 z 方向旋转到任意方向。能量应该相同，但力的 x/y/z 分量会改变。只在 z 轴上测试，会让“把径向力直接写入 z 分量”的错误隐藏起来。

## [bonds.xyz](bonds.xyz)

两原子构型，Å；多帧文件每一帧是独立距离案例。

## [control.toml](control.toml)

控制参数；字段中的 eV、A、K、bar 明确单位，数组仅表示扫描或软件设置。
